# 🎮 QA AI Portfolio Game

Interactive 3D game where users explore QA scenarios and analyze bugs using AI.

## 🚀 Features
- 3D environment (Three.js)
- AI-powered bug analysis
- Interactive zones
- QA-focused experience

## 🧠 Tech Stack
- TypeScript
- Three.js
- Node.js
- OpenAI API

## 🎯 Purpose
Showcase QA + AI integration skills in an interactive way.
